# C# Code Examples

## Описание
В этом файле/проекте содержатся примеры кода на языке **C#**, демонстрирующие работу с основными конструкциями языка, алгоритмами и/или прикладными задачами.

Код предназначен для:
- обучения и практики;
- разбора логики работы программ;
- использования как шаблонов для собственных проектов.

## Структура
- `Program.cs` — точка входа в программу (`Main`)
- Отдельные методы — реализация конкретных задач
- Комментарии в коде поясняют логику работы

## Как работает код
1. Программа запускается с метода `Main`
2. Внутри вызываются необходимые методы
3. Каждый метод выполняет одну логическую задачу
4. Результаты выводятся в консоль (или используются дальше по коду)

## Требования
- .NET SDK (версии 6.0 или выше)
- Любая среда разработки:  
  **Visual Studio / Rider / VS Code**
